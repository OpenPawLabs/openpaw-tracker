# 3D Models

In here you can find all of the 3D Models in `.step` format, along with links to the full CAD designs created in OnShape (a free online CAD software) so that you can make any modifications to fit your own needs!

## 3D Print File

The main file `OpenPaw Trackers.3mf` contains everything needed to print a full set of 8 trackers and their dock. Open this file, and start printing!

All the individual `.step` files are sorted to their own folders in here.

## CAD Models

Want to tweak any of the designs? I remade all of the CAD models so that it is simple to go and modify anything you would like in the future! Hope you find these helpful!
