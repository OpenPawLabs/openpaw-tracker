# DIY Straps 3D Print Parts
You can find all of the files for making your own straps for roughly $10! This is being provided for everyone that is on an extreme budget.

You can find the guide for assembling all of the hardware into the straps here: https://docs.openpawlabs.com

## Credits

The Strap Slides were redesigned from scratch by OpenPaw Labs and is a similar design to the ones created by [`Guidoo` on Thingiverse](https://www.thingiverse.com/thing:1023595), but have been completely reworked for printing simplicity (no supports required) and better grip to prevent the strap slides from moving during use! We are additionally providing a 3-way slide strap so that users can build their own chest harnesses.

The Latches for the straps were designed by [`MoDErahN` on Thingiverse](https://www.thingiverse.com/thing:6929026), and all credit for the latches go to them!
